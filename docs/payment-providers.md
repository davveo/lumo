# 支付渠道参数

后台“系统设置 → 支付方式 → 渠道参数配置”按渠道独立编辑，保存参数与启用开关分开。密钥加密保存、不回显、留空保留；清除需勾选明确字段。每次修改带版本和原因。

微信支付支持应用App ID、商户号、商户证书序列号、API v3密钥、商户API私钥、平台公钥ID及公钥/证书、支付和退款通知地址。API v3密钥校验32字节，商户私钥校验2048位及以上RSA。

支付宝支持应用App ID、生产/沙箱环境、应用私钥、支付宝公钥、异步通知地址和浏览器返回地址。私钥支持PKCS1/PKCS8 PEM及base64编码RSA，使用RSA2所需的至少2048位密钥。

银行卡收单支持实际服务商名称、商户号、应用编号、签名密钥与交易通知地址；具体协议仍由所选收单服务商适配器确定。

通知地址要求HTTPS；演示开发仅允许localhost或127.0.0.1使用HTTP。参数保存只验证格式与完整性，不向第三方发送请求，也不表示商户已签约或回调地址已部署。当前可执行适配器仍为演示支付，真实渠道 adapter_ready=false，不能启用收款，需后续接入验签、回调、查询与退款后联调。

加密主密钥配置、备份与轮换规则同 [登录渠道](login-providers.md)。支付参数存于Payment自己的schema，IAM不访问该数据。

参数依据：[支付宝开放平台应用配置](https://open.alipay.com/module/webApp)、[支付宝公私钥与签名工具](https://open.alipay.com/tool)。
